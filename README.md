# NhostFengBroAI

Nuxt 版鋒兄個人資料工作台，參考 `goldshoot0720/fengbroaiappwrite` 的模組架構重建，並以本地 seed data 呈現 Appwrite CSV 內容。

## Stack

- Nuxt 4 / Vue 3
- TypeScript
- lucide-vue-next
- CSS variables + responsive app shell

## Modules

- 鋒兄首頁 / 儀表
- 鋒兄訂閱
- 鋒兄食品（＋商品庫存）
- 鋒兄筆記
- 鋒兄常用
- 鋒兄圖片 / 影片 / 音樂 / 文件 / 播客
- 鋒兄銀行（+電子票證）
- 鋒兄例行
- 鋒兄工具
  - 鋒兄比價
  - 手機比價
  - 鋒兄Tube
  - 鋒兄金融
- 鋒兄設定
- 鋒兄關於

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
